# DOS 4.0の日本語入力・編集

[MS-DOS Issue #5](https://github.com/kumakumapon/MS-DOS/issues/5)で両リポジトリの作業を追跡します。
JIS/US配列を選べるようにし、ホストOSのIMEで確定した日本語をDOSへ入力します。
同梱FDのEDIT98とDOSのCONでShift_JIS本文を編集・表示・保存します。

起動画面の「MS-DOS 4.0 + RetroBasic で起動」から最新版を起動します。
保存済みの旧版イメージはそのまま利用でき、新版は別のハッシュ付きファイル名で配布します。

「…」→「入力」→「入力設定」→「キーボード」で、物理キーボードの配列を選択します。
日本語JIS 106/109と従来のUS配列に対応し、設定を次回起動時にも復元します。
未設定なら日本語UIはJIS、英語UIはUSです。JISの`@`、`:`、`^`、円記号、`_`は
PC-98の対応する位置へ送り、ゲーム用のキー再割当は指定したキーについて優先します。

`A>`で`EDIT MEMO.TXT`を実行します。「…」→「入力」→「テキスト送信」、
Shiftを2回、またはJISの半角/全角キーで入力欄を開きます。
ホストOSの日本語IMEで変換・確定して「送信」を押します。
「Enter付き」は本文の末尾に改行を付けます。変換中のキーと変換確定のEnterはゲストに送りません。
絵文字などShift_JISで表せない文字は送信前に拒否し、入力欄に残して修正できるようにします。
同梱DOS 4.0では常駐ヘルパーの導入は不要です。エミュレータ画面内の変換を行うDOS単体FEPは含みません。

| エディタのキー | 操作 |
| --- | --- |
| F1、F2 | ヘルプ、開く・新規作成 |
| F3 / Ctrl-S、F4 | 保存、名前を付けて保存 |
| 矢印、HOME / Ctrl-A、End / Ctrl-E | 文字・行移動、行頭、行末 |
| Backspace / Delete、Ctrl-Y | 文字削除、行削除 |
| Ctrl-Z、F5 / Ctrl-F、F6 | 最後の編集の取消・再実行、検索、次を検索 |
| F10 / Esc | 終了（未保存なら保存・破棄・取消を選択） |

`EDIT`と`EDIT98`は同じPC-98用COMです。FD98で本文ファイルを選び`E`でも起動します。
全角文字は2セルで表示し、移動・削除で2バイトを分割しません。
タブ、半角カナ、長い行の横スクロールに対応します。本文は最大16 KiB、ファイル名はASCIIの8.3形式です。
保存はShift_JIS / CRLFで、バイナリや不正な本文は開きません。
保存は一時ファイルをcloseしてから置換し、失敗時は元を保持・復旧します。
復旧パスが表示された場合はファイルを確認してください。詳しくは[EDIT.txt](../public/msdos4/EDIT.txt)を参照します。

`TYPE JPHELLO.TXT`でコンソールの日本語表示を確認できます。FD98のF3も日本語本文を閲覧します。
COMMAND.COMのコマンド名・パス、日本語ファイル名、DOS単体のFEPはこの対応に含みません。

`npm test`は入力変換・保存設定・配布FDと全ファイル・通知を照合します。
`scripts/verify-msdos4.mjs`は本番ビルドを起動ボタンから開き、JIS/USの物理キー、
IMEの未確定・確定・Enter、未対応文字の保持、実際の編集・保存・再読込・TYPEを操作します。
保存ファイルのShift_JIS / CRLFと再起動後の保存内容を読み戻して照合し、画面と検証結果を保存します。
