# KDESK: 電卓・時計・アイコンランチャー

MS-DOS 4.0の起動メニューを選ぶとKDESKが自動起動します。
F10でDOSへ戻り、`KDESK` で再度開けます。
Apps（F2）から Calculator（電卓）と Clock（時計）を開けます。
どちらもデスクトップ内のウインドウで、メモや電卓を使いながら時計が動きます。
F8で最小化、タスクバーで復元、Escapeで閉じる操作ができます。

## 電卓

マウスのボタン、または数字・小数点・`+ - * /`・`=`（Enter）で計算します。
入力順に計算し、`2+3*4=` は20になります。続けて `=` を押すと直前の演算を繰り返します。
整数8桁・小数4桁までの固定小数で、乗除算は小数4桁へ丸めます（ちょうど半分は絶対値を大きくする方向）。
ゼロ除算や範囲超過を表示し、Cまたは数字の入力で再開できます。

| 操作 | 動作 |
| --- | --- |
| C / CE / BS | 計算クリア（メモリ保持）／現在の入力のみクリア／1文字削除 |
| +/- または S | 符号反転 |
| % | 現在の値を100で割る |
| MC / MR / M+ / M- | メモリ消去／呼出／加算／減算 |
| Copy または Ctrl+C | 結果をデスクトップのテキストクリップボードへコピー |
| Paste または Ctrl+V | 符号付き小数を貼り付け。不正な入力では値を保持 |

Memoとクリップボードを共有します。ブラウザーの「その他 → KDESK クリップボードと画像」で
「KDESKから取得」すると結果をホストへコピーできます。「DOSへ貼付」は従来どおりMemoへ入り、
その数値をコピーして電卓へ貼り付けることもできます。

## 時計

DOSの日時（エミュレーターのRTC）を読み、日付・曜日・デジタル時刻とアナログ時計を表示します。
Tまたは12-hour／24-hourボタンで表示を切り替え、Copy／Ctrl+Cで日時をコピーします。
ほかのデスクトップウインドウを操作中も更新します。外部DOSアプリから戻ったときも現在時刻に追従します。
時刻変更はDOSの日時設定を利用してください。

## アイコンランチャー

Apps（F2）はアイコン表示で開きます。1クリックで選択、ダブルクリックまたはOpen／Enterで起動します。
VキーまたはList／Iconsボタンでリスト表示へ切り替えられます。リストでは1クリックで起動します。
左右キーは1項目、上下キーは1行ずつ選び、Homeで先頭へ戻ります。
ウインドウの幅に応じて列数が変わり、小さいウインドウでも選択項目が見えるようスクロールします。

## 同梱と検証

CIが固定したMS-DOSソースからKDESKをビルドし、起動イメージへ組み込みます。
既存のカーネル、ファイラー、エディタ、ドライバーと起動メニューを引き継ぎます。
電卓・時計のために別のCOMファイルを起動する必要はありません。

ブラウザー検証は実際のPC-98ゲストで、電卓の小数演算・メモリ・マウス操作・Memoとのコピー、
時計の進行・12/24時間切替・最小化と復元、アイコンとリストの切替・スクロールを確認します。
既存のウインドウ移動、画像アプリ、保存、DOSアプリの起動、再読み込み後の永続化も検証します。
