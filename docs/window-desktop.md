# Kuma Desktop for PC-98

The MS-DOS 4.0 image generated by CI includes `KDESK.COM`, an original PC-98
window desktop. Choose the MS-DOS 4.0 boot option, then type `KDESK` at `A>`.
It uses PC-9821 PEGC 640 x 400, 256-color graphics and CG-ROM glyphs.
A planar 16-color fallback is available on machines without PEGC.


## Mouse controls

Move/click directly on the emulated screen. The first click waits for mouse
synchronization; use the toolbar's Mouse resync control if the positions drift.
Click Apps/Files/Memo/Help/About to open a window, and click a window to focus it.

| Mouse action | Result |
| --- | --- |
| Drag title bar | Move the full window at pixel resolution while held |
| Drag lower-right grip | Preview size, then resize on release |
| `_` / `x` title button | Minimize / close |
| Taskbar button | Restore and focus |
| Launcher icon | Select; double-click or Open starts it |
| Launcher List/Icons (V) | Toggle icon grid/list; list rows start with one click |
| Files row / double-click | Select / open directory or file |
| Files Parent / Open / ^ / v | Parent directory / open / scroll selection |
| Memo Save / Copy / Cut / Paste / All | Save NOTE.TXT / use the text clipboard |
| Save / Discard / Cancel dialog | Resolve unsaved changes |

A teal desktop, light windows, blue focused titles, shadows and raised buttons
make the controls easier to distinguish. The guest draws its own pointer,
including over text. A mouse driver is not required; keyboard controls also work.

| Key | Action |
| --- | --- |
| F1 / F2 / F3 / F4 / F5 | Help / Launcher / Files / Memo / About |
| Tab | Switch windows; restore a minimized window |
| F6, then arrows, then Enter | Move the active window |
| F7, then arrows, then Enter | Resize the active window |
| F8 | Minimize the active window |
| F9 / Paint menu | Start the image editor |
| Escape | Close the active window |
| F10 | Exit to DOS |

The launcher opens the file manager, text editor, settings panel, installed
BASIC, DOS shell, image viewer, image editor, calculator or clock. Calculator
and Clock are built-in windows that work alongside Memo. See the
[utility and icon launcher guide](kdesk-utilities.md). KVIEW/KPAINT inherit and return the desktop mouse position, so switching
between them and KDESK needs no mouse resync. External DOS programs run one at
a time in the foreground.
Exit the program (use `EXIT` for the shell), then press any key or click to return to the
desktop. Each DOS tool retains its own controls (usually keyboard input). The Files window navigates directories and opens COM/EXE programs,
TXT files in the text editor, BAS files in the installed BASIC, and BMP files in KVIEW.

The built-in memo accepts 1023 ASCII characters. Ctrl+S saves `NOTE.TXT` with
CRLF line endings in the starting directory. Closing or exiting with unsaved
text offers save, discard, and cancel. Failed writes retain the original note;
existing `KDTMP.TMP` or `KDOLD.TMP` prevents replacement. Use the text editor
for Japanese or larger files. Ctrl+A selects the entire memo, Ctrl+C/Ctrl+X
copy/cut it, and Ctrl+V replaces the selection or appends text. Clipboard text
remains available while a foreground DOS program runs.

## Image applications and host clipboard

See [the media guide](kdesk-media.md) for KVIEW/KPAINT and the browser panel.
On PEGC, the palette contains 16 UI colors, a 216-color RGB cube and 24 gradient
shades. Full-window movement caches the scene in the second VRAM page; resizing
uses an outline. Movement falls back to an outline when sprite allocation fails
or on 16-color machines.

## Building the bundled disk

`scripts/prepare-msdos4-cpanel-ci.sh` pins the MS-DOS source commit. It builds
CPANEL, KDESK, KVIEW and KPAINT and updates the disk, manifest, guides and notices in the CI
workspace. Pages deploys that generated disk. The tracked baseline image is
an input to the build; the generated image is uploaded as a CI artifact.
The kernel and existing programs keep their original source provenance.

For a local checkout of the same source commit:

```sh
python3 scripts/update-msdos4-cpanel.py /path/to/MS-DOS --with-window
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --base /webnp2/
CHROMIUM=/usr/bin/chromium WEBNP2_NO_SANDBOX=1 \
  node scripts/verify-msdos4.mjs http://127.0.0.1:4173/webnp2/ test-results/dos4
```

The generated disk contains `KDESK.COM`, `KDESK.TXT`, `KVIEW.COM`, `KPAINT.COM`,
`COLORS.BMP`, `KIMAGE.TXT` and `KDLIC.TXT`; the complete
MIT notice is also included in `LICENSE.txt`. The importer checks that
`scripts/verify-window.mjs` matches the verifier at the pinned source commit.
The browser verification exercises actual guest input including over 200 simultaneous RGB colors, pointer restoration and edge clipping, mouse/keyboard window
management, memo persistence and save errors, directory navigation, and
CPANEL/editor/COM program launches and click-to-return. A separate canvas-event
check covers first-click synchronization, rapid drags and release outside canvas.
The utility suite covers decimal arithmetic, memory, clipboard exchange, clock
progression, 12/24-hour switching, minimize/restore and icon/list navigation,
including narrow windows. The media suite covers text/image clipboard, BMP decoding, drawing, undo/redo,
fill/selection, file protection and the visible browser import/export controls. Screenshots and results are available
in the `bundled-dos-browser-validation` Actions artifact.
