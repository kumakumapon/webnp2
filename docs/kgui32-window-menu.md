# 32bitアプリのタップ用メニュー

ウインドウ左上の **Menu** を1本指でタップすると、アプリの操作一覧を開きます。
右クリック・長押し・ホバーは不要です。Backで戻り、Previous／Nextでページを送ります。
F1、上下／Tab、Enter、Escでも操作できます。日本語／英語の表示切替にも対応します。

- **Editor**：新規・開く・保存・別名保存、検索・置換、すべて選択・範囲選択、コピー・切り取り・貼り付け、Undo／Redo、LF／CRLF、復旧・IME設定・終了。
- **Files**：プレビュー・更新、Root／Work、対応アプリで開く、前後ページ・終了。
- **Images**：読込・保存・復旧、反転・左右反転・Undo・原画像、描画モード、拡大・縮小・等倍・プレビュー・終了。
- **User dictionary**：登録・削除・明示保存・再読込、TMP／BAK確認・復旧、IME切替・終了。
- **Calculator**：メモリ加算・減算・呼出・消去。保持中はMを表示。Cで計算を消してもメモリを保持します。
- **Clock**：12／24時間に加え、ストップウォッチの表示・開始／停止・リセット。DOS時計に基づく1秒単位、最大99:59:59です。午前0時をまたぎ、背景でも進みます。手動の時計変更、1日以上の停止期間の補正、終了後の保持は対象外です。

Editorの範囲選択は、始点へカーソルを置き、Menu→Selection modeを選んでから終点を
タップします。同じ操作でもう一度解除できます。従来のShift選択も継続します。

確認画面やIME未確定入力が開いている間は、Menuに案内とBackだけを表示します。
Menuの保存・復旧・終了も既存の確認、競合検査、原本／TMP／BAK保持を通します。
メニュー中は下の文書や画像へ入力を通しません。

旧32bitアプリは従来どおり動作し、メニューを購読する6アプリだけにMenuを表示します。
描画命令・イベントのABI 1は維持し、メニューは各アプリの私有CPL3メモリで処理します。
実装・SDK契約は [MS-DOS WINDOW-MENU.md](https://github.com/kumakumapon/MS-DOS/blob/main/tools/kgui32/WINDOW-MENU.md) を参照してください。

Actionsの`practical32 / menus`は390px幅のタッチ対応ブラウザで実際のCanvasをタップし、
両GPUの実CPU・私有PTE、メニューのページ送り、電卓メモリ、時計の背景進行、Editorの
未保存確認・取消し、画像Undo、原本・媒体保持、終了後のCPU／XMS／ハンドル回収を検証します。
ローカルpreviewは起動しません。
