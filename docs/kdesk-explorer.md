# KDESK Files and scrollbars

The canonical native controls, limits and validation live in
[MS-DOS: kdesk-explorer](https://github.com/kumakumapon/MS-DOS/blob/main/docs/kdesk-explorer.md).
This repository owns browser distribution and integration; native behavior is documented once.

Choose the MS-DOS 4.0 boot option to start KDESK automatically. F10 returns to DOS;
`KDESK` starts it again. For browser build/source provenance, see
[CI and paired references](ci-maintenance.md). 日本語の入口は[文書一覧](README.md)です。
