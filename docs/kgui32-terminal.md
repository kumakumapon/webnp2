# DOS端末の日本語・文字属性

独立GUIのDOSウィンドウは、各V86アプリのPC-98テキストVRAMを80桁×25行、
文字u16／属性u16の両面として描画します。ASCII、半角カナ、Shift-JIS全角は
同梱CG-ROMを使い、全角の左右それぞれの属性と横スクロール時の片側表示にも対応します。

表示／非表示、青・赤・緑の組合せ、反転、下線、通常モードの縦線、点滅を扱います。
点滅はARTIC時計で進みます。全角文字の右半分にあるカーソルは先頭へ揃えて2桁で表示します。
文字の上位バイトや属性だけの変更も再描画されます。

DOS INT 21hの02h/06h/09h/40h、INT 29h、コンソールエコーはセッション別の
SJIS状態と限定ANSI CSIパーサーを共有します。分割されたSJIS対、行末前の全角折返し、
全角単位の消去、文字と属性のスクロールに対応します。DOS 0Ahの入力編集では全角を
Backspaceで一括消去します。ホストから確定したSJISバイトはフォーカス中のDOSへ届きます。
Editor IMEをDOS常駐FEPとして提供する機能は含みません。

CSIはH/f、A/B/C/D/G、J/K、s/uとSGR 0、30–37/39、4/24、5/25、7/27、8/28に限定します。
PC-98テキストに独立した背景色面はありません。セミグラフィック、外字、任意のGDCモード、
直接GDC描画アプリの仮想化は後続段階です。PM32の従来バイトコンソール契約は維持します。

## 配布と手動確認

HDD単独起動、アプリ配布HDD、完全版FDに同じ`TERM98.COM`を同梱します。
New DOS 1 → Ctrl+E → Ctrl+L → `TERM98.COM`で起動してください。

| キー | 動作 |
| --- | --- |
| a | 日本語行の属性だけを赤に変更 |
| j | 文字ワードの上位バイトだけを変更（日→匂） |
| r | 全角の右半分へ論理カーソルを移動 |
| w | 最終行・最終桁で全角を出力して折返し |
| s | 色付き日本語行を30回出力してスクロール |
| i | DOSバッファ入力とエコー |
| q | 正常終了 |
| f | 私有範囲外への書込みによる診断用ページフォルト |

GUI版K386.TXTはFD作業領域を確保する短いオフラインガイドです。
別配布の基本K386ディスクは従来の完全ガイドを維持します。
生成処理はユーザーのディスクを更新しません。

## 境界と検証

従来のGUI_SNAPSHOT v1と公開XMS ABIは維持し、明示的なv2（8032バイト）で所有する
V86世代の固定2面だけを読み取ります。特権ポインターはCPL3に渡しません。
監視器の既存転送領域992バイト×最大3行を使い、GUIは検証成功したスナップショットだけを採用します。
不正範囲、読取専用出力、世代違い、非所有枠、PM32枠、サイズ／版違いを拒否します。
常駐の割当てを増やさず、リンク時のスタック余裕検査と実行時の境界番兵を検査します。

GitHub Actionsの`KGUI32 DOS terminal`はPEGC／Cirrus×描画／ライフサイクルの4構成です。
実CPUが公開したGUIサンプルと実ページテーブルから私有TVRAMとGUIの受領データを読み、
両面を照合し、独立したCG-ROM期待値と実フレームバッファの画素も比較します。
文字の全ビットと透明度は厳密に検査し、Canvas変換のRGB丸めは各色1階調まで許容します。
テストは実キー／マウスのみで操作し、ゲストメモリを書き換えません。
分割SJIS、半角カナ、属性、点滅、片側クリップ、カーソル、移動／サイズ変更、
他枠との分離と進行、部分SJIS中の強制終了、異常終了からの復帰、HDD／FDの全体ハッシュ、
GUI終了後のXMS・通常メモリ・ベクター復元・スタック番兵まで確認します。
ブラウザーE2EはCIで実行し、ローカルのpreviewサーバーは起動しません。
