# KGUI32 独立32bitデスクトップの開発計画

MS-DOS main 1d5df51d27cd1c0801f014729fb547f89fb82a35 / WebNP2 master
904bfa63ba84777dabfe048e3e1c7dedba62cfcd を基準にする。以下は着手時の計画であり、
実装・検証済みの機能一覧ではない。

最初の完成目標は、KDESKを起動せず、32bitプロテクトモードで画面合成・ウィンドウ管理・
入力を処理する独自デスクトップ。マウスカーソルと移動可能なウィンドウを実装する。
PC-98ゲスト内で動作し、ブラウザのHTMLウィンドウによる代替にはしない。

GUI専用コンテキストを設け、既存PM32/V86アプリ2枠と分離する。表示/入力は管理層の
検証付きAPI経由とし、IRQ内DOS呼び出しや無制限なVRAM/I/O公開を追加しない。
PEGC/Cirrusの実起動、実CPU・メモリ分離、マウス操作と実ピクセル、例外/低メモリ時の
回収、DOS復帰、全FAT12ハッシュと既存CIを検証する。

専用の任意起動イメージを生成し、MS-DOSの検証済みSHAへ固定する。通常版とKDESK/386、
既存の保存ディスクを維持し、生成ディスク/manifest/READMEはコミットしない。
全条件と最新CI成功まではドラフト。MS-DOSマージ→main CI成功→WebNP2マージの順とし、
自動マージしない。

DOS/アプリを新GUI内のウィンドウとして表示する統合、汎用GUI部品SDK、既存アプリの
移植は後続段階。初回の成果と未実装機能を分けて記録する。
