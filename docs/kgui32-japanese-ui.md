# 日本語UIとIME辞書

F8でKGUI32の表示を英語／日本語に切り替えます。初期表示は従来どおり英語です。
デスクトップ、Files、Editor、ファイル選択・復旧、Imagesの保存・復旧、IMEの
主な操作文言を切り替え、開いているアプリと新しく開くアプリに反映します。

切替で文書、選択、Undo、IME未確定文字、ディスク内容を変更しません。
本文、ファイル名、変換候補は翻訳せず、既存のShift-JIS／CG-ROM描画を使います。
翻訳がない技術識別子・文言は英語で表示します。

独自MIT辞書を840読みから1,024読み、18,691バイトへ拡充しました。
画像、保存、バックアップ、復旧、表示言語、実行枠、メモリ保護などの語彙を追加し、
既存候補の順序は保持します。「がぞう→画像」「ふっきゅう→復旧」などを変換できます。
かな／ローマ字・ひらがな／カタカナ・読み全体の変換という操作は従来と同じです。
文節解析、予測、学習、ユーザー辞書は別の開発単位です。

アプリ別翻訳表と、対応SDKだけが受信する言語通知を追加しました。
既存の3144バイト描画要求・32バイト入力イベント・描画文字列上限を維持します。
詳細は[native仕様](https://github.com/kumakumapon/MS-DOS/blob/main/tools/kgui32/JAPANESE-UI.md)。

KDESKガイドとライセンス文書を保持し、完全版FDにも作業用の空きを確保します。

ActionsではPEGC／Cirrusで、切替前後の文書・Undo・未確定文字保持、追加語彙の変換、
新規アプリへの言語反映、日本語ラベルと未確定文字の実CG-ROM画素、終了時回収、
媒体全体の不変性を確認します。ローカルのpreviewは起動しません。
