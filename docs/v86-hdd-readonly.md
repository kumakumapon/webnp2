# V86 HDD読み取り対応の開発契約

MS-DOS #31の次段階。実装・受入は進行中です。V86のDOS仲介をA:と検証済みKHD98
HDDへ拡張し、書込・作成・削除・renameは禁止のまま維持します。ドライブは固定せず
DOSの実DPBと常駐ドライバ記録で検証します。任意のHDD形式やHDD単独起動は別段階です。

VMごとのドライブ・カレントディレクトリ、HDD上のDOSアプリ・子EXEC、読込・seek・
属性・ディレクトリ検索・ハンドルの所有権を検証します。ホストDOSの状態を変えず、
既存FD、別VM/PM32、非対応媒体、例外・強制終了・正常終了の互換と回収を確認します。
公開XMS APIの4096バイト契約とワイヤサイズ、2枠、常駐スタック境界を維持します。

PEGC/Cirrusで実CPU/V86と保存媒体の全バイト不変性をGitHub Actionsから検証します。
このチャットではnpm run previewや代替のローカル配信サーバーを起動しません。
検証・マージ順はMS-DOS → main CI → webnp2 → master CI・公開確認です。
